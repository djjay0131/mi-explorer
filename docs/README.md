# docs/ — the data plane

The artifacts directory declared in `llm/governance/governance-delta.md`
§Repository Layout. Nothing here governs how this repository is operated.

**Belongs here:** figures and plots produced by exercises, written-up
results, external reference material, papers, and derived views of
control-plane documents (a generated ADR index, a rendered roadmap). A
derived view must name the `llm/` document it projects.

**Does not belong here:** governance policy, the delta, ADRs, plans, the
roadmap, the memory bank, execution patterns. Those are control plane and
live under `llm/`. See `CLAUDE.md` for the Q1/Q2 procedure, and
agentic-governance `llm/governance/adr/0001-llm-control-plane-docs-data-plane.md`
for the decision behind the split.

Exercise code is neither plane — it mirrors upstream ARENA at
`chapter1_transformer_interp/` (ADR-0002).

This directory is currently empty apart from this README.
